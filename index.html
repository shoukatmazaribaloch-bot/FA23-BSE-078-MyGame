How to Play

Mode A: Bubbles (Letter Recognition)

At least 5 bubbles float upward simultaneously. Press the corresponding key to pop the bubble before it reaches the top danger ceiling!

Correct Key: Pops bubble, +Points, combo multiplier!
Wrong Key: Penalty deduction (-Score, combo reset).
Escape Miss: Bubble hits top line = Miss recorded.
Session End: Time limit finishes (1, 3, 5, or 10 mins).

Mode B: KeyMagnet (Keyboard Precision)

Targets are magnetized one by one from selected key sets (Home Row, Top Row, etc.). Type each key before the precision timer bar empties!

Speed Bonus: Faster millisecond response awards higher points.
Timeout: If the timer bar runs out, it counts as an error.

Controls & Accessibility

  • • Any Key: Standard QWERTY desktop typing
  • • Touch / Mobile: Tap bubbles directly or tap on-screen keys
  • • M: Toggle Sound effects on/off
  • • Spacebar / Esc: Pause / Resume during gameplay
